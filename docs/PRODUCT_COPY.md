# 产品文案统一规范

## 命名原则

- 用户界面优先使用中文，英文只在命令、代码、协议、日志和诊断信息中保留。
- 同一个概念只使用一个主词，避免在不同页面混用同义词。
- 技术术语可以保留英文，但必须是用户群能理解且翻译会损失准确性的词，例如 Hooks。
- 首次出现可用一句短说明解释概念，后续只使用标准词。

## 标准词表

| 旧词 / 内部词 | 用户界面标准词 | 首次说明 | 使用边界 |
| --- | --- | --- | --- |
| Profile / 配置 / 环境 | 运行配置 | 运行配置用于保存某个 AI 工具的密钥、模型和服务地址。 | UI、官网、README 使用“运行配置”；CLI 命令、代码类型和协议字段保留 profile。 |
| Agent / 桌面端 / Mac | 电脑端 | 电脑端是在电脑上运行 AI 工具并同步会话的部分。 | 普通 UI 使用“电脑端”；健康诊断、日志、开发文档可使用 Agent。 |
| Session / 终端 / 远程终端 / 可恢复终端 | 会话 | 会话是一段在电脑端运行、可从手机查看或继续的 AI 工作过程。 | 列表、历史、恢复、接管都叫“会话”；只有描述输入输出界面时可叫“终端窗口”。 |
| 卡密 / Redeem Card | 兑换码 | 兑换码用于开通或延长会员权益。 | 所有用户文案使用“兑换码”；后端字段和代码可保留 redeem code。 |

## 项目页面命名

项目工作台的 Tab 使用中文加英文括号，Hooks 保留英文：

| Tab key | 标准文案 |
| --- | --- |
| overview | 总览（Overview） |
| sessions | 会话（Sessions） |
| resource | 扩展（Extensions） |
| hooks | Hooks |
| files | 文件（Files） |

相关标题统一：

- Projects -> 项目
- Project Workspace -> 项目工作台
- Recent Sessions -> 最近会话
- Resource / Resources -> 扩展
- Plugin Marketplace -> 扩展市场
- Redeem Card / 卡密 -> 兑换码

## 常见场景句式

运行配置：

- 新建运行配置
- 选择运行配置
- 默认运行配置
- 运行配置名称
- 此工具没有可用运行配置
- 运行配置创建成功

电脑端：

- 电脑端在线
- 电脑端离线
- 电脑端未运行
- 请在电脑端打开 kn
- 绑定电脑端
- 电脑端健康状态

会话：

- 新建会话
- 当前会话
- 会话历史
- 最近会话
- 恢复会话
- 继续会话
- 结束会话
- 允许手机接管此会话

兑换码：

- 兑换码
- 输入兑换码
- 确认兑换
- 正在验证兑换码
- 兑换成功
- 兑换记录
- 购买兑换码

## 禁用词替换表

| 禁用词 | 替换为 | 例外 |
| --- | --- | --- |
| 新建 Profile | 新建运行配置 | CLI 命令示例和开发文档 |
| Profile 名称 | 运行配置名称 | CLI 命令示例和开发文档 |
| 环境管理 | 运行配置 | 明确描述 env var 表格时可用“环境变量” |
| Agent 未运行 | 电脑端未运行 | 健康诊断详情 |
| 桌面端 | 电脑端 | 开发文档 |
| 远程终端 | 会话 | 真实终端输入输出界面可叫“终端窗口” |
| 可恢复终端 | 可恢复会话 | 代码注释可保留 |
| 卡密 | 兑换码 | 无 |
| Resource | 扩展 | 代码类型和测试名 |
| Plugin Marketplace | 扩展市场 | 代码类型和测试名 |
